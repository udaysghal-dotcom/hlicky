# Hlicky

Before doing anything in this repo:

1. Read [plan.md](plan.md) — especially **Execution protocol** and the **Status** table.
2. Read [CONTEXT.md](CONTEXT.md) and use its terms in code, comments, and docs.
3. Read the handover in `docs/handovers/` for the most recent DONE step.
4. Work on exactly one step (the first one not DONE), then write its handover, update the status table, commit, and stop.

No automated tests in this project — verify each step manually per its "Done when".
Never commit `.env` or API keys.
